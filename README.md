# cursorRepo

Local learning apps for this workspace.

## Wortkarte (German flashcards)

**Personal deck (165 words):**  
https://raw.githack.com/nicolasmpicard-gif/cursorRepo/gh-pages/index.html

**Blank / classroom deck:**  
https://raw.githack.com/nicolasmpicard-gif/cursorRepo/gh-pages/share/index.html

**Teacher profile tracker:**  
https://raw.githack.com/nicolasmpicard-gif/cursorRepo/gh-pages/share/admin.html

Each classmate creates a named profile; words stay on their device for free (no login). Profile creation is logged to the tracker above.
Or run locally:

```bash
cd flashcard-app
python3 -m http.server 8080
```

See `flashcard-app/README.md` and `flashcard-share/README.md`.
